## <img src="https://raw.githubusercontent.com/devicons/devicon/master/icons/javascript/javascript-plain.svg" width="24" height="24" /> Technologies Used

This project is built using a collection of modern technologies to ensure fast performance and deliver a high-end visual experience:

- **Frontend Framework**: [React](https://reactjs.org/) & [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **3D Graphics & Rendering**: [Three.js](https://threejs.org/) & [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber/)
- **Animations**: [GSAP (GreenSock Animation Platform)](https://greensock.com/gsap/)
- **Smooth Scrolling**: [Lenis](https://lenis.studiofreight.com/)
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/) & [Lucide React](https://lucide.dev/)

## <img src="https://raw.githubusercontent.com/devicons/devicon/master/icons/git/git-original.svg" width="24" height="24" /> How to Use

You are free to clone, use, and modify this portfolio template for your personal needs. Make this template a solid foundation to showcase your digital identity and work to the world!

### Installation:

1. **Clone this repository**
   ```bash
   git clone https://github.com/username/repo-name.git
   ```
2. **Navigate to the project directory**
   ```bash
   cd repo-name
   ```
3. **Install dependencies**
   ```bash
   npm install
   ```
4. **Run the local development server**
   ```bash
   npm run dev
   ```
